# MLOps Course - AMMI

This repository contains the materials for the MLOps course at AMMI. Each folder is structured by the day of the course and contains the corresponding lecture slides and lab materials.

## Repository Structure

The repository is organized by the day of the lesson. Each day has its own folder containing lecture slides and a lab folder with all relevant materials for the hands-on exercises.

## Course Contents

### Day 1: Introduction to MLOps & Data Pipelines
- Machine Learning pipeline basics
- Iris dataset classification
- Python environment setup

### Day 2: Experiment Tracking with MLflow
- MLflow fundamentals
- Experiment logging and tracking
- Model registry

### Day 3: Data Processing & Pipelines
- Data preprocessing workflows
- Pipeline orchestration basics

### Day 4: FastAPI & Async Programming
- Building ML APIs with FastAPI
- Authentication and security
- Asynchronous programming patterns

### Day 5: Containerization with Docker
- Docker fundamentals
- Containerizing ML applications
- Docker Compose for multi-service apps

### Day 6: Testing & Quality Assurance
- Unit testing for ML code
- Integration testing
- Code quality tools

### Day 7: Model Monitoring
- Drift detection with Evidently & Alibi Detect
- Production monitoring strategies
- Real-time model health checks

### Day 8: Workflow Orchestration
- Apache Airflow fundamentals
- DAG creation and scheduling
- GitHub Actions integration

### Day 9: Cloud VM Deployment ⭐ NEW
- Remote VM setup on GCP/AWS
- SSH and remote access
- Deploying Airflow on cloud VMs
- Linux process namespaces
- Production service management

## Usage

1. Navigate to the relevant day's folder (1day, 2day, ... 9day).
2. Review the lecture slides pdf for the concepts covered during that session.
3. Open the lab folder for hands-on exercises:
    - Go through the lab slides pdf for an overview of the session.
    - Attempt the tasks outlined in the markdown file. The file also contains the solutions.
    - Check the code folder for any provided code necessary for the tasks.

### Special Note for Day 9

Day 9 requires students to set up their own cloud VMs. Please review:
- `9day/README.md` - Lab overview and structure
- `9day/VM_SETUP_GUIDE.md` - Instructor guide for VM requirements
- `9day/lab/day9.md` - Detailed student instructions
- `9day/lab/QUICK_REFERENCE.md` - Command cheat sheet

**Students need:** A Google Cloud or AWS account with free-tier access
